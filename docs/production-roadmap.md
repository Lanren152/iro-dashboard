# 生产化清单

v0.2已经跑通研究软件闭环，但生产投入前仍必须完成：

1. 取得正式数据授权，导入真实公司全集、行业映射、财务、行情、一致预期和产业指标；
2. 为各细分行业建立特有指标、领先/确认/风险关系、发布时间、季节性和历史修订规则；
3. 建立公告PDF下载、表格抽取、页码坐标、跨页表格和人工复核机制；
4. 建立公司业务分部、客户、供应商、产能、单位经济性和资本配置数据层；
5. 将基础反向PE模型扩展为一致预期修订、估值分位和反向DCF；
6. 用真实OpenAI/Anthropic密钥进行输出质量、成本、延迟和双模型分歧测试；
7. 建立严格按当时可得信息的历史回放、概率校准和未来数据泄漏检查；
8. 建立交易日历、分布式任务锁、优先级队列、速率限制、失败隔离和成本预算；
9. 增加账户权限、密钥保险库、数据授权审计、数据库迁移、备份恢复和监控；
10. 保持研究系统与任何交易执行系统物理和权限隔离。
