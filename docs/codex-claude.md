# Codex 与 Claude Code 协作

## 运行关系

投资研究 OS 是长期运行的主体。Codex 和 Claude Code都是客户端：它们通过 MCP 读取系统数据、创建研究假设、运行研究周期、检查证据和修改研究状态。关闭某次 AI 会话不会丢失任何研究状态。

## Codex

项目的 `.codex/config.toml` 已配置 Streamable HTTP MCP。启动 MCP 服务后，在可信项目中打开 Codex即可使用。Codex主要承担代码开发、连接器实现、数据校验、测试修复和系统演进。

## Claude Code

项目的 `.mcp.json` 已配置同一 MCP 服务。Claude Code 适合长文档阅读、产业链推理、跨文档对照和独立反方审查。

## 推荐协作规则

- 日常扫描只运行一个主研究模型；
- 达到高分候选或模型分歧较大时，再调用第二模型独立审查；
- 两个模型都不得直接修改原始资料；
- 任何状态变更都通过 MCP 工具写入审计记录；
- 任何代码改动都必须通过测试后合并。
