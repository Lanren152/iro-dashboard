# 数据契约

## 最低必需字段

每一条原始文档必须包含：来源类型、来源名称、标题、来源 URL、发布时间、数据所属期间、内容哈希、原始文件位置、解析文本、可信度和是否演示数据。

每一条行业指标必须包含：指标代码、所属行业、观测期间、数值、单位、频率、正向或反向含义、来源名称和来源 URL。

每一条研究证据必须包含：原始资料 ID、影响变量、正负方向、证据类型、独立证据路径、置信度和是否已经交叉验证。

## 事实等级

1. 法定披露或官方统计；
2. 授权产业数据库；
3. 上下游/同行交叉披露；
4. 管理层预测；
5. 媒体和研报线索；
6. AI 推断。

较低等级信息可以创建验证任务，但不能单独推动机会进入候选阶段。
